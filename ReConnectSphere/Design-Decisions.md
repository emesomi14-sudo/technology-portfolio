# ReConnectSphere: Design Decisions

## Visual Identity

ReConnectSphere uses a consistent visual style to create a welcoming and accessible experience for young people who have moved to the UK.

- **Navy (#18213b):** Used to provide structure and visual consistency.
- **Coral (#ef5b4c):** Used to highlight important elements and create contrast.
- **Cream (#fff9f5):** Used as a light background to support readability.
- **Inter:** Used as the main typeface for clear, consistent text.

## Navigation and Structure

The website is divided into five main sections:

1. Homepage
2. Community
3. Opportunities
4. Report a Concern
5. Safety and Privacy

This structure allows users to find information through clearly defined sections.

## Content and Accessibility

The website uses straightforward language and organised page layouts to make information easier to understand.

The design aims to:
- Make important information easy to find.
- Use consistent navigation across pages.
- Present support information clearly.
- Create a respectful space for different cultural experiences.

## Safety and Privacy

ReConnectSphere does not include private messaging or live chat. Instead, it provides information and signposting to relevant organisations and support services.

## Design Rationale

The design decisions were informed by the research findings and the needs identified for the intended audience. The overall approach prioritises accessibility, clarity, cultural respect and user safety.
