# ReConnectSphere: Technical Overview

## Technology Stack

| Technology | Purpose |
|---|---|
| WordPress | Website development and content management |
| Figma | Interface design and layout planning |

## Website Structure

ReConnectSphere is organised into five main sections:

1. Homepage
2. Community
3. Opportunities
4. Report a Concern
5. Safety and Privacy

## Design Approach

The website uses a consistent visual identity, with a navy, coral and cream colour palette and Inter typography.

Navigation and content are organised to help users locate relevant information.

## Development Approach

The website was developed using WordPress. Its structure and content were informed by questionnaire responses, interviews and research findings.

## Technical Considerations

Development priorities included:

- Clear navigation between sections.
- Consistent page layouts.
- Readable content.
- Privacy-conscious design.
- Appropriate signposting to external support.

## Future Technical Development

Potential improvements include:

- More extensive accessibility testing.
- Responsive design evaluation across different devices.
- Structured user testing and feedback.
- Further refinement of navigation and content.
