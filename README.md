## Featured Project: ReConnectSphere

**Independent CREST Gold Project | September 2025 – Present**

[Visit the ReConnectSphere website](https://reconnectsphere.com)

ReConnectSphere is a support website designed to help young people who have recently moved to the UK navigate everyday life, education and social connections.

I am developing the project through a user-centred approach, using research to identify needs and inform design decisions.

**My work includes:**
- Designing and conducting questionnaires and semi-structured interviews.
- Analysing research findings to identify user needs and common challenges.
- Translating findings into website requirements.
- Designing page layouts and user journeys using Figma.
- Developing the website using WordPress.
- Considering accessibility, privacy, safeguarding and clear communication.
